Citepage

A help center and an /ask box. The box may only speak with a citation.

What it is

Citepage hosts documentation pages and answers questions against those pages. If retrieval returns nothing, the product refuses.

API

GET /api/pages
GET /api/pages/:slug
POST /api/ingest {title, body}
POST /api/ask {q}
