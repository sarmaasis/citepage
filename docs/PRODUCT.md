# Citepage product

## Promise

Host your help center. Answer only from the page. Cite the paragraph. Refuse when the page is silent.

## Job

Stop a solo founder answering the same pricing / SSO / API questions in email.

## Buyer

- US/EU B2B SaaS, 1–15 people
- Public or pasteable docs already exist
- Will not pay Mintlify (~$250) this quarter

## Surfaces

| Surface | Job |
|---|---|
| Marketing `/` | Start desk |
| Desk `/app.html` | Index pages, ask, see citations |
| Docs `/docs.html` | Product documentation |
| API `/api/*` | ingest + ask |

## Pricing

- Starter $29 — subdomain, /ask
- Pro $49 — custom domain, no mark
- Billing: Dodo (not wired in v0.1)

## Rules

1. No citation, no answer.
2. No unlimited generation.
3. One primary CTA per page.
